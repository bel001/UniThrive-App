# Capturas — UniThrive

Estas capturas se generan desde los widgets reales de la app con datos de demostración. Son la fuente de las imágenes que aparecen en el [README principal](../README.md).

- **Formato:** PNG de 860 × 1864 (viewport lógico 430 × 932, densidad 2×).
- **Tema:** oscuro “Vivid Academic”.
- **Generador:** `test/generate_capturas_test.dart`.
- **Regenerar:** `flutter test test/generate_capturas_test.dart`.
